# Certificate Download App (Next.js + TypeScript)

This module is the user-facing certificate download portal.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4.2
- Zod + React Hook Form validation

## Features

- Shared PIN login
- Certificate lookup by `roll_no` or `email`
- Secure download endpoint with auth cookie checks
- Client-side and server-side validation
- Case-insensitive certificate ID handling for download links

## Setup

```powershell
cd X:\git-projects\e-certificate-generator\web
npm install
Copy-Item .env.local.example .env.local
```

## Run

```powershell
npm run dev
```

Open `http://localhost:3000`.

## Validation Commands

```powershell
npm run lint
npm run build
```

## Environment Variables

- `CERT_PORTAL_PIN`: Shared host PIN.
- `CERT_PORTAL_AUTH_SECRET`: Secret used to sign auth cookies.
- `CERTIFICATE_OUTPUT_DIR`: Directory containing generated `.png` certificates.
- `CERTIFICATE_INDEX_PATH`: Manifest file generated by the Python CLI (`index.json`).

## Data Contract

The Python generator writes `output/index.json` with records like:

- `certificate_id`
- `name`
- `roll_no`
- `email`
- `file_name`

The web app uses this manifest for lookup and download.
