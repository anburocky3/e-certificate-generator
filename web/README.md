This module is the user-facing certificate download portal.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4.2
- Zod + React Hook Form validation

## Features

- Shared PIN login
- Certificate lookup by `roll_no` or `email`
- Secure download endpoint with auth cookie checks
- Client-side and server-side validation
- Case-insensitive certificate ID handling for download links
- Visible session expiry banner after PIN login
- Optional host-defined certificate download expiry deadline
- Host-only status dashboard at `/host/status`
- Host member download tracking with Upstash Redis persistence

## Health Check Endpoint

Use this to verify manifest and sample certificate files after deployment:

- `GET /api/health/certificates`

This endpoint is host/admin protected. Log in at `/host/login` first.

It returns:

- `200` with `ok: true` when manifest + sampled files are readable
- `503` with `ok: false` when manifest/files are unavailable

This is useful on Vercel to confirm your `public/certificates/index.json` and image files are packaged correctly.

## Environment Variables

- `CERT_PORTAL_PIN`: Shared host PIN.
- `CERT_HOST_PORTAL_PIN`: Host/admin-only dashboard PIN (falls back to `CERT_PORTAL_PIN` when omitted).
- `CERT_PORTAL_AUTH_SECRET`: Secret used to sign auth cookies.
- `CERTIFICATE_OUTPUT_DIR`: Directory containing generated `.png` certificates. For Vercel, use `certificates` (or `public/certificates`).
- `CERTIFICATE_INDEX_PATH`: Manifest file generated by the Python CLI (`index.json`). For Vercel, use `certificates/index.json` (or `public/certificates/index.json`).
- `CERT_DOWNLOAD_EXPIRES_AT`: Optional download cutoff timestamp (ISO 8601), for example `2026-12-31T23:59:59Z`.
- `UPSTASH_REDIS_REST_URL`: Upstash Redis REST URL (optional locally, recommended on Vercel).
- `UPSTASH_REDIS_REST_TOKEN`: Upstash Redis REST token.

## Data Contract

The Python generator writes `output/index.json` with records like:

- `certificate_id`
- `name`
- `roll_no`
- `email`
- `file_name`

The web app uses this manifest for lookup and download.

## Vercel deployment tip

If you want a web-only deploy, generate certificates straight into `web/public/certificates` so Vercel packages them as static assets:

```powershell
cd X:\git-projects\e-certificate-generator
python main.py --output-dir web/public/certificates --overwrite
```

Then set the web app environment variables to:

- `CERTIFICATE_OUTPUT_DIR=certificates`
- `CERTIFICATE_INDEX_PATH=certificates/index.json`

### Upstash Redis for download tracking

To persist download status in serverless deployments:

1. Add the Upstash Redis integration to your Vercel project.
2. Ensure `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN` are available in Vercel env.
3. Redeploy.

When Redis is configured, download status on `/host/status` is stored in Redis and remains persistent across function invocations.
When Redis is not configured, the app falls back to manifest-only status (best effort for local/self-hosted writable filesystems).
